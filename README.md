# بدلات المؤسسة — IN & OUT

موقع مركز الكيلاني للأغذية لتسجيل بدلات المؤسسة العسكرية، وربط رقم المادة لدى المؤسسة برقم النظام في SAP، ونسخ الأكواد والكميات بنفس ترتيب البنود.

## الوظائف

- تسجيل OUT المسلّم للمؤسسة وIN المأخوذ منها، مع الشوفير والفرع ورقم الأوردر.
- حساب القيم والفرق واقتراح أصناف قريبة بالقيمة.
- تحويل الحبات والكراتين إلى وحدة SAP المعتمدة لكل صنف.
- نسخ الأكواد والكميات والوحدات أو كود + كمية بصيغة Tab، مع نسخ يدوي احتياطي.
- سجل مركزي في D1، وحفظ مباشر دون موافقات أو توقيع.

## التشغيل والفحص

يتطلب Node.js 22.13 أو أحدث وpnpm.

```sh
pnpm install --frozen-lockfile
pnpm dev
node scripts/test-exchange.mjs
pnpm exec tsc --noEmit
pnpm build
```

ملفات التطبيق في `app/`، ومنطق التحويل والنسخ في `app/lib/exchange.ts`، ومخطط البيانات في `db/schema.ts`، والترحيلات في `drizzle/`.

## النشر والوصول

الموقع الحالي: https://kilani-military-exchanges.almqablen.chatgpt.site

هذه نسخة مصدر من آخر إصدار منشور، مرجعه `9ce222481caaa4dc9ddfe23eb0d5789730eb2202` في مستودع الاستضافة. مستودع GitHub هذا لا يفعّل نشرًا تلقائيًا إلى Sites بمجرد رفع الملفات.

التطبيق يعتمد على سياسة الوصول الخاصة بمالك الموقع في طبقة استضافة Sites، وعلى ربط D1 باسم `DB`. عند نقل الاستضافة يجب توفير حماية مكافئة لجميع مسارات `/api/data` قبل إتاحتها. ملف `.openai/hosting.json` يحتفظ بهوية الموقع الحالي.

السجل التشغيلي وتعديلات الأسعار والربط المحفوظة في قاعدة البيانات ليست ضمن Git. ملفات JSON تحتوي القوائم الأساسية فقط. الربط غير المكتمل يمنع نسخ الكميات ويُعرض للمراجعة دون إسقاط البنود.

لا تُرفع مفاتيح أو ملفات بيئة أو ملفات قاعدة البيانات المحلية إلى المستودع.
